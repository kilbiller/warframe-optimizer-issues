# Warframe Optimizer issues

Warframe Optimizer finds the best mod build for a Warframe weapon against a given target. It picks mods, arcane, Exilus, stance and Riven within the game's slot, capacity and polarity limits, then scores each build by simulating the kill. Everything runs in your browser.

The source code lives elsewhere, so this repo is just for feedback. [Open an issue](https://github.com/kilbiller/warframe-optimizer-issues/issues/new/choose) to request a missing weapon or report a wrong solver result.
